ใช้บัญชีที่เข้าสู่เว็บไซต์ Grimmory เพื่อจัดการ Library และ Metadata

Readest และ KOReader รับรหัส KOSync ในแอปอ่านโดยตรง
มีเซสชันพร้อมใช้งาน

ระบบจะตรวจสอบเซสชันเมื่อเรียกข้อมูล

เตรียม Sync หนังสือครั้งแรก

ให้ Adapter จับคู่ไฟล์กับหนังสือใน Grimmory ได้อัตโนมัติ

ตั้งค่าครั้งเดียว สำหรับหนังสือทุกเล่มใช้บัญชีฐานข้อมูลที่อ่านได้อย่างเดียว กรอกข้อมูลด้านล่างเพื่อสร้างค่าตั้งค่า แล้วนำไปใส่ในไฟล์ .env ของ Adapter
การตั้งค่าขั้นสูงและสิทธิ์ฐานข้อมูล

ใช้ path ภายใน Adapter/container บัญชีต้องมีสิทธิ์ SELECT บน book, book_file, library และ library_path หากใช้ Docker ให้ระบุชื่อ service ฐานข้อมูลใน network เดียวกัน

ยังไม่มีการเปลี่ยนค่าบนเซิร์ฟเวอร์

ข้อมูลในฟอร์มนี้อยู่ในเบราว์เซอร์เท่านั้น · ค่าที่คัดลอกมีรหัสผ่าน เก็บไฟล์ .env เป็นส่วนตัว

A LITTLE GUIDANCE

เริ่มใช้งานได้ใน 3 ขั้นตอน

  1. เชื่อมต่อด้วยบัญชีที่ใช้เข้าสู่เว็บไซต์ Grimmory
  2. คัดลอกค่าฐานข้อมูลไปใส่ .env แล้ว restart Adapter
  3. เปิด “ตรวจสอบระบบ” เพื่อดูว่าพร้อม Sync หรือยัง

บัญชีแต่ละส่วน

Grimmory ใช้จัดการ Library และ Metadata ในหน้านี้

KOSync ใส่ใน Readest หรือ KOReader เพื่อ Sync ตำแหน่งอ่าน

Database ใช้ค้นหาหนังสือจากไฟล์

ใช้ในวง LAN ได้ผ่าน IP ของเครื่อง หรือ Grimmlink.local:8085 เมื่อเปิด mDNS และเครือข่ายรองรับ

UNDERSTAND YOUR STATUS

อ่านผลได้ง่าย ๆ

พร้อมใช้งาน การตรวจสอบผ่าน

ควรตรวจสอบ มีค่าที่อาจต้องตั้งเพิ่ม

พบปัญหา ดูวิธีแก้ใต้รายการนั้น

ก่อนแชร์รายงาน

รายงานไม่รวมรหัสผ่านหรือ token แต่อาจมี IP และ path ในเครื่อง ควรอ่านก่อนส่งให้ผู้อื่น

mDNS ที่ประกาศได้ ยังไม่ยืนยันว่าอุปกรณ์อื่นใน LAN เข้าถึงได้
